# Adivina el número 🎯

Juego de consola hecho en Python. El objetivo es adivinar un
número aleatorio entre 1 y 100 siguiendo las pistas del programa.

## Funciones

- Genera un número aleatorio.
- Indica si el número secreto es mayor o menor.
- Cuenta los intentos válidos.
- Valida las entradas.
- Permite salir de la partida.
